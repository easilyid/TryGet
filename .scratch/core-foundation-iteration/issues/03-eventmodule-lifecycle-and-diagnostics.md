## What to build

Harden EventModule as the single global typed event channel for Core. This slice should protect struct-event publishing, EventScope lifecycle ownership, dispatch-time subscribe/unsubscribe behavior, handler exception diagnostics, nested publish protection, and registry snapshot accuracy for generated handlers.

## Acceptance criteria

- [x] Publish/Subscribe/Unsubscribe works for struct event types and preserves subscription order.
- [x] Duplicate subscriptions fail consistently, while unsubscribing a missing handler remains safe according to the public contract.
- [x] Subscribe and Unsubscribe during Publish are deferred until the current dispatch completes and produce deterministic next-publish behavior.
- [x] Handler exceptions are reported through EventModule diagnostics and do not prevent later handlers from running.
- [x] Nested Publish stops at the documented depth limit with an actionable error.
- [x] EventScope disposes all scoped subscriptions, supports repeated Dispose as no-op, and prevents disposed scopes from leaving new handlers subscribed.
- [x] EventHandlerRegistry Snapshot includes every generated handler metadata entry, including multiple handlers from one assembly and legacy unknown registrations.
- [x] Tests cover lifecycle behavior through IEventModule/EventScope APIs rather than private handler lists.
