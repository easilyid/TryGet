# TGTask Scheduler Cancellation Contract

## Parent

.scratch/core-foundation-iteration/PRD.md

## What to build

Harden TGTask and TGTaskScheduler as the Core async foundation. This slice should verify that pooling, version checks, manual Abort, owner-scope cancellation, phase-aware scheduling, scaled/unscaled time, combinators, and unobserved exception behavior all compose without leaks or stale-handle bugs.

## Acceptance criteria

- [x] TGTask and TGTask<T> stale handles fail or complete according to the documented version semantics and do not observe reused bodies.
- [x] Await consumption returns eligible bodies to the pool exactly once.
- [x] TGTask.Abort cancels pending manual tasks, no-ops for completed/default/expired tasks, and rejects builder-created async method return tasks.
- [x] TGCancelSource/TGCancelToken can cancel multiple scheduler-created pending tasks and leave none of their cancellation registrations active after completion or cancellation cleanup.
- [x] TGTaskScheduler Yield, Delay, WaitForFrames, and DelayUntilPhase resume in the requested FramePhase and respect scaled versus unscaled time.
- [x] Scheduler Shutdown cancels all pending tasks and resets elapsed time/frame diagnostics.
- [x] WhenAll and WhenAny consume completed tasks, surface exceptions/cancellation predictably, and do not leak task bodies for losing WhenAny branches.
- [x] OperationCanceledException/TGTaskAbortException from expected cancellation paths does not enter UnobservedException reporting.
