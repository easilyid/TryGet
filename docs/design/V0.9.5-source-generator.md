## 1. 调研结果汇总（2026/05/24）

### 1.1 IIncrementalGenerator vs ISourceGenerator

| API | 状态 | 性能 | 用法 |
|----|------|------|------|
| `ISourceGenerator`（旧） | Deprecated 风格 | 每次编译完整重跑 | TEngine GameEventSourceGenerator 仍在用（2024 后停止维护风险） |
| **`IIncrementalGenerator`（新）** | **推荐** | 缓存友好，值相等模型短路重计算 | 2024+ 主流生态（Roslyn 4.0+，.NET 6+） |

**决策**：**V0.9.5 全程使用 `IIncrementalGenerator`**，匹配 2026 主流实践。

关键技术点：
- `[Generator(LanguageNames.CSharp)]` Attribute 标记
- `Initialize(IncrementalGeneratorInitializationContext context)` 入口（host 内仅调一次，所有 Compilation 复用）
- Pipeline 用 **value-equatable** 模型（record / struct + IEquatable），让 Roslyn 缓存命中短路
- **`ForAttributeWithMetadataName`**：attribute-driven 场景的零成本扫描入口
- **`RegisterPostInitializationOutput`**：在 user code compile 前注入 marker attribute 定义

### 1.2 Unity 集成约定

| 约定 | 内容 | 出处 |
|------|------|------|
| 源码放 `<Project>~` 文件夹 | 末尾波浪号 `~` 让 Unity 完全忽略此目录（不生成 .meta、不索引） | Unity 官方代码生成指南 |
| DLL 放 `Runtime/` 或 `Editor/` 内 | 加 `RoslynAnalyzer` label（Inspector 中勾选） | Unity Manual `roslyn-analyzers.html` |
| netstandard2.0 target | Unity 6 / 2022.3+ 支持的 Generator 运行时 | 官方推荐 |
| asmdef scope 规则 | **Generator DLL 所在 asmdef 必须被 consumer asmdef 直接/间接引用**，否则不触发 | Unity Discussion 923345 |

**反模式**（避免）：
- ✗ 把 Generator 源码直接放 Unity Assets 内（会被当 runtime 代码编译）
- ✗ 试图引用 Read-only Package 的 asmdef（无法修改其引用，须 embed 才行）
- ✗ Generator 内引用 UnityEngine（Generator 跑在 Roslyn host 里，无 Unity 上下文）

### 1.3 Dual-Trigger Init 模式（Unity + .NET 通用）

**问题**：生成的注册代码需要在两种宿主下自动触发：
- .NET console：用 `[ModuleInitializer]`（C# 9.0+）
- Unity：用 `[RuntimeInitializeOnLoadMethod]`（Unity 内置，IL2CPP-friendly）

**主流方案**（参考 GenEvent 项目）：

```csharp
// Generator 输出：
internal static class __AssemblyManifest
{
#if UNITY_5_3_OR_NEWER
    [UnityEngine.RuntimeInitializeOnLoadMethod(UnityEngine.RuntimeInitializeLoadType.BeforeSceneLoad)]
#endif
    [System.Runtime.CompilerServices.ModuleInitializer]
    public static void Initialize()
    {
        // 生成的 Register 代码
    }
}
```

**坑**：
- `[ModuleInitializer]` 要求 C# 9.0+ 和 `internal` 可见性
- Unity 端 IL2CPP **会 strip** RuntimeInitializeOnLoadMethod 方法 → 需加 `[UnityEngine.Scripting.Preserve]`
- 同方法同时挂两个 attribute 在 Unity Mono 下会**触发两次**（已观察） → 用全局 `_initialized` flag 防重

### 1.4 参考实现对标

| 框架 | Generator 形态 | TryGet 取舍 |
|------|--------------|-----------|
| **TEngine** GameEventSourceGenerator | ISourceGenerator（旧）+ EventInterfaceGenerator | 抛弃旧 API，但参考其"扫接口生成实现类"模式 |
| **BigCat** Wjybxx.BigCat.Apt | 自研 Poet builder + APT pattern（重） | 不抄，TryGet 直接用 StringBuilder + ForAttributeWithMetadataName |
| **Fantasy** SourceGenerator | 不可访问（deepwiki 不索引） | 文档描述中"Module 自动注册"是核心，TryGet 复刻此 idea |
| **hsenl** HsenlScriptsGeneratorEditor | Editor 脚本（runtime 不参与） | 不是真正 SourceGen，不参考 |
| **Entitas** Roslyn 迁移 | 在做中（issue #1005） | 关注 multi-asmdef 设计模式 |
| **GenEvent**（Puring103） | IIncrementalGenerator + dual-trigger | **直接参考其 dual-trigger 模式**（最贴近 V0.9.5 需求） |

### 1.5 V0.6-V0.9 留存的"手动注册"痛点

V0.9 完整落地后业务代码状态：

```csharp
// 手动注册 Module（V0.6 起一直如此）
var host = Bootstrap.CreateHost(BootstrapOptions.Default);
host.Register<ILogModule>(new ConsoleLogModule());
host.Register<ITimerModule>(new TimerModule());
host.Register<IConfigSource>(new MemoryConfigSource());
// ... ~10 行 boilerplate

// 手动注册 System
group.AddSystem(new MovementSystem());
group.AddSystem(new RenderSystem());
// ... 每加一个 System 改一行

// 手动 Subscribe EventBus

// ... 每加一个 Handler 改一行
```

**目标**：V0.9.5 用 `[Module]` / `[SystemRegister]` / `[EventHandler]` Attribute 替代上述手动注册。

## 2. API 详细设计

### 2.1 `[Module]` Attribute + AssemblyManifest

**Attribute 定义**（generator embed，业务无需手写）：

```csharp
[System.AttributeUsage(System.AttributeTargets.Class, AllowMultiple = false)]
internal sealed class ModuleAttribute : System.Attribute
{
    /// <summary>Module 注册的服务接口类型（如 <c>typeof(ILogModule)</c>）。</summary>
    public System.Type ServiceType { get; }
    public ModuleAttribute(System.Type serviceType) { ServiceType = serviceType; }
}
```

**业务用法**：

```csharp
[Module(typeof(ILogModule))]
public sealed class ConsoleLogModule : ILogModule { ... }
```

**Generator 生成**（每 asmdef 一份）：

```csharp
// <auto-generated by TryGet.SourceGenerator>
namespace TryGet.Generated
{
    internal static class __AssemblyManifest_MyAssembly
    {
        private static bool _initialized;

#if UNITY_5_3_OR_NEWER
        [UnityEngine.RuntimeInitializeOnLoadMethod(UnityEngine.RuntimeInitializeLoadType.BeforeSceneLoad)]
        [UnityEngine.Scripting.Preserve]
#endif
        [System.Runtime.CompilerServices.ModuleInitializer]
        public static void Initialize()
        {
            if (_initialized) return;
            _initialized = true;
            AssemblyManifestRegistry.Register(host => {
                host.Register<ILogModule>(new ConsoleLogModule());
                // 每个 [Module] 标记类一行
            });
        }
    }
}
```

**配套 Core 改动**：
- 新增 `Core/Module/AssemblyManifestRegistry.cs`：全局 `Action<IModuleHost>` 收集器
- `Bootstrap.CreateHost` 内最后调 `AssemblyManifestRegistry.ApplyAll(host)` 触发所有生成的 Register

### 2.2 `[SystemRegister]` Attribute

```csharp
[System.AttributeUsage(System.AttributeTargets.Class, AllowMultiple = false)]
internal sealed class SystemRegisterAttribute : System.Attribute
{
    public System.Type SystemGroupType { get; }
    public System.Type PhaseType { get; }
    public int Order { get; }
    public SystemRegisterAttribute(System.Type systemGroupType, System.Type phaseType, int order = 0)
    {
        SystemGroupType = systemGroupType;
        PhaseType = phaseType;
        Order = order;
    }
}
```

**业务用法**：

```csharp
[SystemRegister(typeof(GameLoopSystemGroup), typeof(UpdatePhase), order: 10)]
public sealed class MovementSystem : SystemBase { ... }
```

**Generator 生成**：在 AssemblyManifest 内追加 System 注册（按 group 分组）。

### 2.3 `[EventHandler]` Attribute

```csharp
[System.AttributeUsage(System.AttributeTargets.Method, AllowMultiple = false)]
internal sealed class EventHandlerAttribute : System.Attribute { }
```

**业务用法**：

```csharp
public sealed class GameplayHandlers
{
    [EventHandler]
    public static void OnDamage(DamageEvent evt) { ... }
}
```

**Generator 生成**：

```csharp
internal static class __EventHandlers_MyAssembly
{
    [System.Runtime.CompilerServices.ModuleInitializer]
    public static void Subscribe()
    {
        // 此时 host 还没构造，所以收集到 EventHandlerRegistry
        EventHandlerRegistry.Register<DamageEvent>(GameplayHandlers.OnDamage);
    }
}
```

**配套 Core 改动**：新增 `Core/Module/EventHandlerRegistry.cs`，`Bootstrap.CreateHost` 触发所有 Subscribe 到生成 host 的 EventBus。

### 2.4 IComponentSystem<T> 自动调度（V0.9 IPureComponent 配套）

V0.9 PRD 指出："IComponentSystem 自动调度留 V0.9.5 Source Gen"。

**业务用法**（V0.9 已有 IComponentSystem<T>）：

```csharp
public sealed class HealthSystem : IComponentSystem<HealthComponent>
{
    public void OnAttach(Entity entity, HealthComponent component) { ... }
    public void OnDetach(Entity entity, HealthComponent component) { ... }
}
```

**Generator 生成**（在 Entity.AddComponent/RemoveComponent 路径 hook 自动 dispatch）：

```csharp
internal static class __ComponentSystemRegistry
{
    [ModuleInitializer / RuntimeInitializeOnLoadMethod]
    public static void Initialize()
    {
        var sys = new HealthSystem();
        ComponentSystemHooks<HealthComponent>.AttachHook += sys.OnAttach;
        ComponentSystemHooks<HealthComponent>.DetachHook += sys.OnDetach;
    }
}
```

**配套 Core 改动**：
- `Core/Entity/ComponentSystemHooks.cs`：`internal static class ComponentSystemHooks<T> where T : IPureComponent { public static event Action<Entity, T> AttachHook; public static event Action<Entity, T> DetachHook; }`
- `EntityPureComponentExtensions.AddComponent` 内调 `ComponentSystemHooks<T>.AttachHook?.Invoke(entity, component)`
- 同 RemoveComponent 调 DetachHook

## 5. 风险点

| # | 风险 | 缓解 |
|---|------|------|
| 1 | Generator csproj 改动后 Unity 不自动重编 DLL | 文档化"改 Generator 后 dotnet build + 复制 DLL 到 Runtime/Core/Generators/" 工作流；可选 PostBuild target 自动 copy |
| 2 | RoslynAnalyzer label 在 Unity 端 Inspector 设置丢失 | DLL.meta 文件 commit 进 git，包含 RoslynAnalyzer flag |
| 3 | `[ModuleInitializer]` + `[RuntimeInitializeOnLoadMethod]` 双触发 | 生成代码内用 `_initialized` flag 防重 |
| 4 | IL2CPP strip Initialize 方法 | 加 `[UnityEngine.Scripting.Preserve]` + 文档化 |
| 5 | asmdef 引用规则误用（业务 asmdef 不引用 Generator asmdef → Generator 不运行） | 文档 + Sample asmdef 示范 |
| 6 | 多 asmdef 时 AssemblyManifest 类名冲突 | 类名包含 assembly hash 或 `__AssemblyManifest_<AssemblyName>` 命名 |
| 7 | EventHandlerRegistry 在 Bootstrap.CreateHost 之前先 ModuleInit 触发 | Registry 用静态队列收集，CreateHost 后 ApplyAll 触发实际 Subscribe |
| 8 | Generator 自身测试基建 | 用 Microsoft.CodeAnalysis.CSharp.Test 包 + Snapshot 测试（Verify pattern） |
