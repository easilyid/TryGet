# V2.0 PRD — 路线 C：客户端服务框架 + 轻量场景栈

> **撰写日期**：2026/05/25
> **状态**：Accepted / Implemented（V2.0 已落地，2026/05/30 提交到 `v2.0-route-c-landing` 分支；Unity EditMode 测试待 Editor 验证后并入 main）
> **前置**：基于 TEngine / BigCat / hsenl / Fantasy 四框架对比分析
> **核心决策**：从"双端框架"转向"纯客户端服务框架"，ECS/IPlugin/服务端契约全部移除

---

## 1. 目标

让 TryGet Core 成为一个**精简、现代、客户端专用**的 Unity 游戏框架骨架：
- 管好服务生命周期（ModuleHost）
- 管好游戏流程（Procedure Stack）
- 提供类型安全的模块间通信（IEventBus）
- 提供零外部依赖的异步原语（TGTask）
- 通过 Source Generator 消除样板代码

**不做**：
- 不做 ECS / EC 模型（交给 Unity 原生 GameObject 或 DOTS）
- 不做服务端抽象（INetServer / ITickLoop / 连接管理）
- 不做横切插件系统（IPlugin / IPlugPoint）
- 不与 Unity 的游戏对象管理竞争

## 4. Procedure Stack API 设计（吸收 BigCat SceneMgr.stack）

### 4.1 IProcedure 升级

```csharp
public interface IProcedure
{
    void OnEnter(IProcedureModule module);
    void OnExit(IProcedureModule module);
    void OnPause(IProcedureModule module);   // ★ 新增
    void OnResume(IProcedureModule module);  // ★ 新增
    void OnUpdate(IProcedureModule module, float deltaTime, float unscaledDeltaTime);
}
```

### 4.2 IProcedureModule 升级

```csharp
public interface IProcedureModule : IModule, IUpdateModule
{
    // 注册
    void AddProcedure(string id, IProcedure procedure);

    // 启动
    void Start(string initial);
    void Stop();

    // 栈操作 ★ 新增
    void Push(string target);    // 暂停当前 → 进入新 Procedure
    void Pop();                  // 退出当前 → 恢复上一个
    void Replace(string target); // 退出当前 → 进入新

    // 查询
    string Current { get; }
    int StackDepth { get; }      // ★ 新增
    bool IsRunning { get; }
}
```

### 4.3 语义定义

| 操作 | 当前 Procedure | 目标 Procedure | 栈变化 |
|------|---------------|---------------|--------|
| `Push("B")` | A.OnPause() | B.OnEnter() | [A] → [A, B] |
| `Pop()` | B.OnExit() | A.OnResume() | [A, B] → [A] |
| `Replace("C")` | B.OnExit() | C.OnEnter() | [A, B] → [A, C] |
| `Start("A")` | — | A.OnEnter() | [] → [A] |
| `Stop()` | 全部 OnExit() | — | [...] → [] |

### 4.4 IAsyncProcedure 扩展

```csharp
public interface IAsyncProcedure : IProcedure
{
    TGTask OnEnterAsync(IProcedureModule module);
    TGTask OnExitAsync(IProcedureModule module);
    // OnPause/OnResume 保持同步（暂停/恢复应该是即时的）
}
```

## 5. ModuleHost 变更

### 5.1 移除 IPluginHost 继承

```csharp

// After (V2.0):
```

### 5.2 移除 Plugin 相关代码

ModuleHost.cs 中删除：
- `_pluginsByPoint` 字段
- `AddPlugin / RemovePlugin / GetPlugin / GetPluginsAt / PluginCount`
- `Update` 中 BeforeUpdate/AfterUpdate plugin 触发
- `Shutdown` 中 plugin Uninstall 逻辑

移除 `AssemblyManifestRegistry.ApplyAll` 和 `EventHandlerRegistry.ApplyAll` 中对已删除 Registry 的引用（SystemRegistry 删除后 Bootstrap 无需变更，因为 Bootstrap 从未调用 SystemRegistry）。

## 10. 与参考框架的定位对比

| 维度 | TEngine | BigCat | TryGet V2.0 |
|------|---------|--------|-------------|
| 定位 | 纯客户端 | 双端 | 纯客户端 |
| Module 管理 | 静态 GetModule | Worker + DI | ModuleHost + Service Locator |
| 流程管理 | ProcedureModule (FSM) | SceneMgr.stack | ProcedureModule (Stack) ★ |
| 事件 | int/string ID | 无全局事件 | 泛型 struct（类型安全） |
| 异步 | UniTask | Coroutine + Promise | TGTask（自研） |
| ECS | 无 | Scene + GameUnit | 无 |
| Source Gen | 事件接口 | RPC Proxy | Module + EventHandler |

TryGet V2.0 的差异化：**Procedure Stack（BigCat 启发）+ TGTask（自研 async）+ 泛型事件 + Source Gen 自动注册**。
